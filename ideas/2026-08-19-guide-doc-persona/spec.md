# 기능 정의: 가이드 문서 관리에 페르소나

## 왜 여기인가

가이드 문서는 사실(무엇을 아는지)이고 페르소나는 말투·규칙(어떻게 말하는지)이다. 메뉴가 갈라져 있으면 문서를 올린 뒤 페르소나를 빼먹고 Q&A를 만들어, 지식 DB에는 말투가 안 들어가고 실시간 대화에만 붙는 일이 생긴다.

그래서 **가이드 문서 관리** 안에 페르소나 탭을 둔다. 챗봇 설정 쪽 페르소나가 이미 있어도, 이 화면이 학습 직전 편집·적용의 정본이다.

## 화면

가이드 문서 관리 = 탭 세 개.

| 탭 | 하는 일 |
| --- | --- |
| 문서 | 업로드, 분석, 분류 확정. 내용은 사실만. 말투 문장을 매뉴얼에 넣지 않음 |
| 페르소나 | 역할, 말투, 금지, 모를 때 행동. 문서 기반 초안, 미리보기 |
| 학습 | 확정 문서로 Q&A 생성. **현재 페르소나를 적용**이 기본 |

## 페르소나 필드

| 필드 | 설명 |
| --- | --- |
| 표시 이름 | 대화에 쓸 봇 이름 |
| 역할 | 예: 사내 가이드 안내, 고객 상담 |
| 경어 | 존댓말 / 반말 |
| 말투 | 간결 / 상세, 격식 / 캐주얼 |
| 성격 | 짧은 형용사. 예: 차분, 단정 |
| 금지 | 줄마다 하나. 추측, 이모지, 경쟁사 언급 등 |
| 모를 때 | 문서에 없으면 하지 말 것. 예: 추측 금지, 담당 안내 |
| 추가 규칙 | 학습·런타임 공통. 예: 답 끝에 출처 문서명 |
| 학습에 적용 | 켜면 Q&A 생성 시 이 페르소나를 씀. 기본 켜짐 |

저장은 문서 재업로드가 아니다. 이미 만든 Q&A 문체는 자동으로 바뀌지 않는다. 문체를 맞추려면 학습 탭에서 해당 문서만 **기존 Q&A에 추가**로 다시 생성하거나, 항목을 손으로 고친다.

## 학습과의 연결

1. 문서 분류 확정
2. 페르소나 저장 (학습에 적용 = 켜짐)
3. 학습: 생성 방식은 운영 중이면 **기존 Q&A에 추가**. 새로 생성은 초기화이므로 확인 모달

추가 요청사항(버튼, 표)은 페르소나와 별 칸이다. 페르소나 = 말투·금지, 추가 요청 = 그 배치 Q&A 형식.

## 하지 말 것

- 가이드 PDF 본문에 “존댓말로 답하라”를 넣는 것
- 페르소나 저장만으로 기존 Q&A 전체를 다시 쓰는 것
- 문서 탭과 페르소나 탭을 다른 메뉴로 다시 쪼개는 것
