# 트리마제 38A · 방3 통로형 드레스룸

성수동 트리마제 **38A(84A)** 첨부 평면에서 방3 입구 옷장(흰색 박스)을 **통로형 드레스룸**으로 바꾼 계획안이다.

Figma: [방3 통로형 드레스룸](https://www.figma.com/design/OC05MDCqKCCfXx4xhmcC0b)

## 치수 근거

세대 내부 **현장 실측은 공개되어 있지 않다.** 세움터 허가도면·인테리어 실측표는 인증·비공개라 여기서 구할 수 없었다.

사용한 근거는 다음뿐이다.

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 타입 | 38A / 84A | 단지 평형 표기 |
| 전용 / 공급 | 84.82㎡ / 126.66㎡ | 실거래·중개 공시 |
| 해당 면적 세대 | 97세대 | 분양 당시 84A |
| 사용승인 | 2017-05-29 | 건축물 정보 |
| 방3·옷장 mm | 평면도 스케일 환산 | 첨부 38A 도면 비율 + 전용면적 |
| 문·옷장·통로 모듈 | 800 / 600 / 900 | 국내 공동주택 관례 |

도면에 적힌 mm는 **환산값**이다. 시공·가구 발주 전에 해당 세대에서 벽체, 문틀, 창호, 천장고를 다시 재야 한다.

## 방3 변경

기존: 입구 좌상단 문 800, 바로 오른쪽 상단벽에 함몰 붙박이 옷장.

변경(통로형):

1. 기존 옷장 철거
2. 입구에서 침실로 관통하는 **통로 900 mm** (문과 정렬)
3. 통로 우측·상부에 **행거 깊이 600 mm** (기존 옷장 자리 + 실내 쪽 확장)
4. 드레스룸 존 깊이 **1,500 mm**, 침실 잔여 깊이 **1,700 mm**
5. 드레스룸–침실 사이 경량 가벽 100 mm, 개구 900 mm (문 없음)

동선: 복도 → 방3 문 → 드레스룸 통로 → 침실.
