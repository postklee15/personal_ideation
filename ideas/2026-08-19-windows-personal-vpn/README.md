# Windows PC에서 개인 VPN 운영

- 날짜: 2026-08-19
- 상태: draft
- 한 줄: 밖에서 붙는 VPN 서버는 Windows에 올릴 수 있다. 공인 IP가 없으면 포트포워딩형 서버는 실패하고, 메시(Tailscale)가 먼저다

## 메모

범위는 **외부에서 연결해 집 Windows를 거쳐 가는 서버**다. 상용 VPN 클라이언트(다른 나라 IP)는 이 폴더의 대상이 아니다.

집 PC를 서버로 쓰면 출구 IP는 집 회선이다. 해외에서 한국 사이트가 필요할 때는 맞고, 미국 IP가 필요할 때는 틀린 도구다.
